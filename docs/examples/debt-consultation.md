## 具体行动步骤

### 1. 列出事实与诉求，先核对时间节点

时间安排：现在；如文书期限更早，以核实后的法定期限为先

办理渠道：深圳的相关正式受理窗口；事实整理可先自行完成

材料：本人收到的通知或决定及送达凭证、关键事件时间线、当前诉求与已采取行动

- 把“想低成本追回”拆成具体请求，金额项目分别列出。
- 每件事记下何时、谁、做了什么和证据编号；本人亲历、对方说法和推测分开。
- 把约定履行日、收文日及文书写明的截止日单列，先向正式受理窗口核实时限和提交方式。

完成标志：形成一页事实时间线、一份请求清单和待核对的期限表。

不顺利时：日期记不清时先找通知、订单、银行流水或送达记录；不要自行补造日期，也不要因等材料而错过办理期限。

### 2. 按要证明的事实整理材料

时间安排：现在开始，正式提交前再次核对原件

办理渠道：本人设备、银行或平台导出渠道及合法保管材料的机构

材料：借条、转账记录、催款记录

- 借条：找完整聊天、对账或催还回复，与转账逐笔对应；不要倒签或补造借条。 要说明：双方是否约定借款、还款日及利息。
- 转账记录：从银行或支付平台导出含交易号、双方账户、日期和金额的流水。 要说明：是否实际交付及尚欠本金。
- 催款记录：保留完整催还对话和送达记录，按每笔借款整理。 要说明：还款承诺、到期及催告情况。

完成标志：每项请求均有对应证据编号；缺口明确标记，不把上传文件等同于已证明事实。

不顺利时：找完整聊天、对账或催还回复，与转账逐笔对应；不要倒签或补造借条。；现金交付可查当时取现记录、收据和在场证人，单一取现记录不能直接证明交付。；可发一份真实、克制的书面对账请求并保存对方回复。

### 3. 先提出一次清楚、可留痕的处理请求

时间安排：关键材料已整理后；紧急安全或临近期限时立即办理

办理渠道：对方已确认的书面联络或正式平台工单渠道

材料：事实摘要、分项诉求、借条、转账记录

- 我们先核对这笔款的用途、收到日期和已还金额。请书面确认尚欠金额及可履行的还款安排；如有异议，请说明是哪一笔。
- 记录提交时间、材料版本、接收人或工单号；将答复与承诺逐项记下。
- 协商等待时间由双方实际情况决定，不当作法定期限，也不因等待回复搁置法定救济。

完成标志：取得回执或可核实的书面回复，并明确下一处理节点。

不顺利时：不愿接收或不回复时保留提交记录，转下一正式渠道；涉及暴力、威胁或强制措施时不要自行当面对质。

### 4. 核实法源、管辖和请求后提交材料

时间安排：确认法定期限、条件及受理机关后及时提交

办理渠道：有管辖权的人民法院诉讼服务中心或人民法院在线服务

材料：适配该程序的申请书或诉状、依法要求的身份及主体证明、证据目录和附件、送达信息及联系方式

- 先核对借款人身份和有效联系方式，再核对被告住所地、合同履行地及是否有有效争议解决约定；准备起诉材料，利息单列并核查适用上限。
- 按受理机关最新官方清单填写事实与理由，一项请求对应一组事实和证据；不能证明的部分注明。
- 保存提交凭证；收到补正要求后逐项补齐，核对补正期限、缴费及是否已正式受理。

完成标志：拿到可查询的收件或受理信息，并确认后续举证、缴费、开庭或办理节点。

不顺利时：被退回时先取得具体原因，区分材料不足、主体或管辖问题；依据告知补正或核实救济途径，避免反复盲目提交。

### 5. 准备对方抗辩与后续落实

时间安排：收到对方意见或机关通知后，按载明期限准备

办理渠道：有管辖权的人民法院诉讼服务中心或人民法院在线服务

材料：争点与证据对照表、对方答复、已达成协议或处理文书、履行记录

- 对方可能称是赠与、已还款、实际借款人另有其人或利息过高。
- 用约定用途的对话、交付记录和还款明细逐笔回应；不把转账金额直接当作全部未偿本金。
- 协议或文书形成后记录履行主体、金额或事项、节点和收款情况；和解前核对是否放弃其他请求，签字内容逐字看清。

完成标志：每个争议有事实和证据回应；结果有具体履行安排，并持续核对执行情况。

不顺利时：协商、投诉或调解未解决时重新比较正式救济成本；文书生效后仍不履行的，核对是否可依法申请执行及其条件。
